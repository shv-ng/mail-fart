# 💨 Mail Fart

A Chrome extension that plays custom sound effects when keywords appear in your Gmail messages.


https://github.com/user-attachments/assets/d9623423-aa71-4edf-aba2-6caca7d09d54



## Features

- Match keywords in any open Gmail message
- Upload any audio file, any format, any size
- Assign multiple sounds to one keyword — plays one at random
- Preview sounds before saving
- All sounds stored locally in your browser, nothing sent anywhere

---

## Setup

1. Download or clone this repo
2. Go to `chrome://extensions`
3. Enable **Developer Mode** (top right)
4. Click **Load unpacked** and select the project folder
5. Pin the extension, click it, hit **Open Settings**
6. Add your keywords and upload sounds
